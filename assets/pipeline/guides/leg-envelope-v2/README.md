# Relaxed-only leg silhouette guide — draft v2

This is a simplified technical reference for fresh one-shot generation.

- One target envelope only; no regular or puffy bands.
- Smooth rounded hidden thigh dome.
- One shallow setup articulation through the knee.
- Continuous calf taper without a separate calf lobe.
- Fixed bottom opening at the shared ankle height.

`relaxed-silhouette-ref-v1.png` is the transparent generation reference.
`relaxed-silhouette-review-v1.png` is a dark-background review rendering.

It contains no costume, folds, palette or boot design. Those must come from the
approved outfit references. Status: draft until tested in generation and Rig Lab.
