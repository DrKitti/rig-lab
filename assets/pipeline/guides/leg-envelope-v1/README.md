# Shared leg garment envelope guide — draft v1

Purpose: a construction reference for part generation, not a runtime texture.

- Neutral body is the minimum anatomy inside clothing.
- Regular and relaxed are reusable garment envelopes.
- Puffy max is a ceiling, not a target.
- The orange relaxed envelope is the current Time Travel target.
- Hip, knee, ankle and sole landmarks stay fixed across outfits.
- Yellow bands are mesh-bending zones where hard trim and tiny details should be avoided.

Files:

- `leg-garment-envelope-guide-v1.png` — annotated review image.
- `leg-garment-envelope-ref-v1.png` — clean aligned reference for generation trials.

Status: draft for visual review. It has not yet been accepted as a pipeline standard.
