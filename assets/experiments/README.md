# Curated experiment archive

Not runtime input and not included in the Vite build or portable game export.

- `rigs/`: historical rig JSON, including user experiments. Original IDs are retained.
- `history/`: previously committed migration evidence, snapshots and source artwork.
- `evidence/`: selected failed/iterated leg comparisons and review annotations.
- `runtime-origins/`: earlier runtime/source images before path and colour consolidation.
- `checkpoint-before-organization/`: the three current rigs and shared clips re-read just
  before cleanup; recoverable user data, not an alternative current setup.

Some historical rig paths refer to ignored local drafts which are not shipped. These records
preserve decisions/data, not a promise that every historical trial is runnable from a clone.
Use the current three rigs for live work. Start with `docs/experiments.md` for lessons and
`assets/pipeline/checkpoint-manifest.json` for old-to-new paths and provenance hashes.
